# Эмодзи в GitHub Markdown

GitHub поддерживает использование эмодзи с помощью специальной разметки: `:имя_эмодзи:`. Эмодзи можно вставлять в любые части markdown-документа: заголовки, списки, таблицы, цитаты и т.д.

## Примеры использования

- `:smile:` → 😄
- `:rocket:` → 🚀
- `:tada:` → 🎉
- `:bug:` → 🐛
- `:fire:` → 🔥

```markdown
- Исправлена ошибка :bug:
- Добавлена новая функция :rocket:
- Успешное завершение задачи :tada:
```

**Результат:**

- Исправлена ошибка 🐛
- Добавлена новая функция 🚀
- Успешное завершение задачи 🎉

## Как узнать имя эмодзи

1. Используйте [официальный список GitHub emoji](https://github.com/ikatyang/emoji-cheat-sheet) или [gist с полным списком](https://gist.github.com/rxaviers/7360908).
2. Введите `:` и начните печатать имя — GitHub предложит автодополнение.

## Встраивание эмодзи в текст

```markdown
### Важные моменты :star2:

> Не забудьте проверить код! :eyes:
```

**Результат:**

### Важные моменты ✨

> Не забудьте проверить код! 👀

## Использование эмодзи в заголовках и списках

```markdown
### :memo: Заметки

- :white_check_mark: Сделано
- :x: Не сделано
```

**Результат:**

### 📝 Заметки

- ✅ Сделано
- ❌ Не сделано
